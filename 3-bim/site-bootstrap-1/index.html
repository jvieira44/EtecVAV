Por que usar Bootstrap?

O Bootstrap facilita a criação de sites modernos, bonitos e responsivos. Ele oferece diversos componentes e classes prontas que ajudam no desenvolvimento e economizam tempo

O que é

Um framework front-end com classes CSS e componentes prontos para montar páginas sem escrever todo o estilo do zero

Importância

Permite criar páginas de forma mais rápida e organizada, usando menus, botões, cards e formulários já prontos

Responsivo

O sistema de grid se adapta automaticamente a computadores, tablets e celulares, sem esforço extra
