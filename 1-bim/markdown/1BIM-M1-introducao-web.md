## 1-HTTP e HTTPS

* HTTP é um protocolo de comunicação utilizado para a transferência de informações em sistemas de rede. Ele permite que o computador peça e receba informações, como imagens, arquivos e páginas web. Com esse sistema uma pessoa em São Paulo pode acessar uma informação que está localizada em qualquer outro lugar do mundo.

* O HTTPS é a versão mais segura do HTTP, que é usado para acessar sites na internet. A principal diferença é que o HTTPS protege os dados usando criptografia. Por conta disso hoje a maioria dos sites usam HTTPS.

* O HTTPS é importante pois, protege seus dados na internet, ele criptografa para impedir que outras pessoas vejam ou roubem informações, como senhas e cartões. Além disso o HTTPS garante que o site acessado é verdadeiro, evitando fraudes ou golpes.
## 2-NAVEGADOR e SERVIDOR WEB.

* O papel do navegador é converter o código-fonte dos websites, por exemplo HTML, CSS ou até mesmo JavaScript, para uma interface gráfica que pode ser interagida para que o usuario possa navegar, sem o acesso ao navegador de internet, o usúario fica limitado a somente fisualizar somente linhas de código indesifraveis.

* O papel do servidor web é armazenar, processar e enviar o conteúdo dos sites como de exemplo o HTML, CSS, imagens e videos para o navegador dos usúarios. com isso pode se dizer que ele e responsavel por receber dados de HTTP/HTTPS processando as para que possam ser acessiveis e rapidos. 

* A comunicação feita pelo servidor web e o navegador e feita por meio de um modelo cliente-servidor. Fazendo a utilização de um protocolo HTTP/HTTPS sobre uma conexsão TCP/IP. Sendo como um processo de "pedido-resposta" que acontece em Milissegundos.

## 4-PERGUNTAS DE REFLEXÃO

* Os padrões da Web, como HTTP, HTML e DNS, são importantes porque criam uma “linguagem comum” para a internet. Graças a eles, diferentes sistemas conseguem se entender e trocar informações sem problemas.

* Eles também garantem que navegadores e servidores funcionem juntos corretamente. Por exemplo, quando você acessa um site, o DNS encontra o endereço, o HTTP faz a comunicação, e o HTML organiza o conteúdo que você vê na tela.

* Na prática, isso permite que um mesmo site funcione em vários navegadores e dispositivos, como celular ou computador. Sem esses padrões, cada site só funcionaria em sistemas específicos, e a internet seria muito mais limitada e confusa.
