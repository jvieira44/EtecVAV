O que é HTML?

O HTML é uma das principais linguagens utilizadas para criar páginas da web. Ele é responsável por estruturar o conteúdo de um site,
organizando textos, imagens, links e outros elementos que vemos ao navegar. Em outras palavras, o HTML é a base de qualquer página na internet,
servindo como o “esqueleto” que dá forma e sentido ao conteúdo exibido no navegador.

Criador do html: Tim Berners-Lee

Tim Berners-Lee desenvolveu o HTML enquanto trabalhava no CERN, com o objetivo de facilitar o compartilhamento
de informações entre cientistas. Ele se inspirou em um conceito chamado hipertexto, que permite navegar entre textos clicando em links.

Para que isso funcionasse, ele criou três tecnologias fundamentais:
HTML - linguagem para estruturar o conteúdo das páginas
HTTP - protocolo para transferência de dados
URL - sistema de endereçamento de páginas

Curiosidade:

Tim Berners-Lee não patenteou sua invenção, permitindo que a web fosse gratuita e aberta, um dos principais motivos para seu crescimento explosivo.
